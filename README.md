# Selected-Political-Jokes-of-Soviet-Eastern-Europe

## 苏联东欧政治笑话选编-小特警重排版

### 简介

**声明：本人完全支持中国特色社会主义，支持中国共产党的领导。**

本书文本来源于zlib上辽宁省革委会宣传组刊印的《苏联东欧政治笑话选编》，经由本人对原扫描版pdf进行肉眼识别加OCR辅助。本人对原书进行了重新排版，还对部分重点进行了突出处理，方便各位同志直接查看或导入电子书细品。由于本人常用markdown而不是word，而且是肉身手打，有所纰漏还请多多谅解。

### Claude Code Skill（可选）

本仓库同时内置了一个 **Claude Code skill：`soviet-joke`**，让 AI 直接以本书为语料库讲苏联笑话。

- 位置：`.claude/skills/soviet-joke/`
  - `SKILL.md` — 技能指令（调取逻辑、讲述流程、输出格式）
  - `tell.py` — 选题/排版脚本：随机选笑话、剥离主题序号、按固定格式输出，从根上保证「主题不带一二三四」「末尾无空行」（不依赖模型自觉）
  - `corpus.md` — 语料库副本（干净重排版后的全文，独立嵌入，技能可整体移植到任意项目）
- 用法：对 Claude Code 说「讲个苏联笑话」「再来一个」「tell me a Soviet joke」即可触发。
- 行为：由 `tell.py` 从语料库**随机**选题并排版；只做必要的时代/讽刺对象一两句中性铺垫；正文**逐字照录**、不改一字；不做当代政治引申。
